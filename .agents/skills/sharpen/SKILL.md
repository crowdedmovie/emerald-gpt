name: sharpen
description: "Rewrite the user's prompt with a more rigorous method and keep the task within its scope."
disable-model-invocation: true
---

Before rewriting the task within its current scope, do four things.

1. Identify the practice a skilled professional would add within the existing scope.
2. Name the primary source material they would start from.
3. Name the specific methods and tools available in the current environment.
4. State the evidence that would independently show the result is right.

Rewrite the user's prompt to ask for that work.

Leave decisions that belong to the user open.

Keep the response to the rewritten prompt. If the user needs evidence to choose between options, describe the smallest useful experiment and the result it should measure.
